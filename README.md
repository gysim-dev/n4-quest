# N4 QUEST — 간격 반복 학습 업데이트

index.html을 Chrome/Edge에서 열거나 GitHub Pages에 업로드하세요.

- 문제별 학습 기록을 브라우저 localStorage에 저장
- 오답은 3문제 후 재출제 시도, 이후 10분 복습
- 정답 시 복습 간격: 10분 → 1일 → 3일 → 7일 → 14일 → 30일
- 복습 예정 문제 우선 출제, 신규 문제 병행
- 사이드바에서 복습 예정 수 확인 및 복습 던전 실행
- 기존 기록을 보존하면서 새 SRS 필드 자동 추가

참고: 일정은 고정 간격 기반의 교육용 휴리스틱이며 개인별 최적 간격을 보장하지 않습니다. 브라우저 데이터를 지우면 기록도 삭제됩니다.
